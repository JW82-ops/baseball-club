# 프로야구팀을 만들자

신생 구단을 창단해 선수를 키우고 KBO 정상에 도전하는 구단·선수 육성 시뮬레이션.

**플레이:** https://jw82-ops.github.io/baseball-club/

## M1 (현재)
- 세부 능력치(타자 6종·투수 5종), 숨겨진 잠재력, 성장 타입(조숙·표준·대기만성·꾸준), 특성, 나이 곡선
- 주간 훈련(강도·개인 포인트), 피로·컨디션, 부상, 잠재력 각성
- 1군/2군, 라인업·로테이션·불펜 편집
- KBO 10구단 시즌, 모든 경기를 타석 단위로 시뮬레이션, 개인 기록·순위
- 문자중계, 박스스코어, KBO식 포스트시즌, 시상
- 오프시즌: 은퇴·노화, 5라운드 신인 드래프트, 스프링캠프
- 세이브 자동 저장(버전 관리)·내보내기/불러오기

## v5 (현재)
- 투구 단위 엔진: 구종·코스·스윙·컨택·파울, 타자 핫/콜드 존, 카운트별 타구 질 · 중계 스트라이크존
- 야구 교실: 용어·규칙·지표·작전 60여 개, 선수 카드 세부 지표(WAR·wRC+·FIP 등) 탭하면 설명
- 프런트: 전력분석·의무·마케팅·스카우트 부서, 스카우트 지역 파견, 모기업 이사회 목표·지원금
- KBO 제도: 샐러리캡, FA 등급·보상선수, 2차 드래프트, 웨이버, 육성선수, 올스타전, 골든글러브
- 육성: 주간 훈련 시간표, 코치 궁합, 폼 교정, 투수 이닝 관리, 해외 윈터리그, 재활군 프로그램
- 아트: 3D 애니메이션풍 SD 캐릭터 286종(국적별), 도시 엠블럼 14종, 구장 32장, 사계절 연출, 3D 아이콘

## v4
- 승부처 작전 선택(대타·강공·번트·도루 / 불펜·고의4구·믿고 간다), 하이라이트 리플레이, 응원가·캐스터 멘트
- 병역(상무·현역·국제대회 면제), WBC·아시안게임·프리미어12 국가대표, 퓨처스리그 기록·시상
- 라이벌전, SNS 반응, 데뷔·마일스톤·은퇴식·라스트 시즌, 기자회견
- 신구종 연마·포지션 전환·해외 캠프 유학, 슬럼프·핫스트릭
- 업적 23종, 저장 슬롯 3개, 유니폼 디자이너, 난이도(AI 투자 수준)
- 3D 애니메이션풍 아트(Higgsfield): 배경 16장(`img/art`), SD 캐릭터 114장(`img/sd`) — 선수는 나이대·투타·외국인별로 배정돼 나이가 들면 얼굴도 바뀌고, 감독·코치·스카우트는 경력별 얼굴, 메일 발신 NPC 10종
- 탭마다 장소 배경(우리 구장·클럽하우스·2군 훈련장·관중석·구단주실·계약 책상)

## v3
- 구장·클럽하우스·2군 파크 → 레벨별 부속시설 칸, 부속시설 21종(Lv.1~3), 공사 기간·동시 공사 2곳
- 감독(전술·육성·리더십·마운드 운용 + 성향)·코치·2군 감독·트레이너·스카우트 세부 능력치
- 선수 기분(요인별)·성격·충성도·선수 간 관계·팀 케미, 구단주 메일함·약속 시스템
- 브랜드 가치 기반 스폰서 등급(지역→전국→대기업→글로벌), 슬롯별 계약·보너스 조건
- 연봉 협상·FA 선언/협상·FA 시장·트레이드(AI 제안 포함)
- 기록실·주간 야구 신문, 우승 시 NPB → MLB 승격

## 로드맵 (완료)
- M2: 2D 필드 연출, 감독 작전
- M3: 연봉·계약·FA·트레이드
- M4: 시설·스태프 → 육성 반영, 재정 고도화
- M5: 기록실·뉴스·명예의 전당, NPB·MLB 승격
